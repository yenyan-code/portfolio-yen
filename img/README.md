# Image Assets Directory (`img/`)

This directory is structured to match your reference project (`yen-tweaking`).

## How to add your own images:
1. **Logo / Avatar**: You can drop your personal logo here as `yen final logo.png` (or any filename) and update the `<a class="nav-avatar">` in the HTML headers from text `A` to `<img src="img/yen final logo.png" alt="Logo">`.
2. **Project Screenshots**: If you want to replace the interactive CSS-generated mockups (`<div class="mockup-ui">`) with actual PNG/JPG screenshots of your designs, place them in this folder and replace the mockup div with an `<img src="img/your-screenshot.png">` tag!
