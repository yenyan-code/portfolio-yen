# Arien Destriza — UI/UX Design Portfolio ✨

Welcome to the source code of my personal portfolio website! 

This repository contains the code for my digital portfolio, where I showcase my case studies, UI/UX design projects, and creative explorations. 

🌍 **Live Site:** https://portfolio-arien.vercel.app/

## 🛠️ Built With

This portfolio was built from scratch without heavy frameworks to ensure lightning-fast load times and complete control over the design system:

* **HTML5** for semantic, accessible structure
* **Vanilla CSS** with a custom design system (CSS variables, flexbox/grid)
* **Vanilla JavaScript** for dynamic theme toggling and lightweight logic
* **View Transitions API** for seamless, app-like cross-document page transitions
* **Lenis** for premium, buttery-smooth scrolling

## ✨ Key Features

* **Dynamic Dark/Light Mode:** A gorgeous, system-aware theme toggle that instantly switches the entire site's color palette with zero lag.
* **App-like Page Transitions:** Uses the modern CSS View Transitions API to create beautiful slide-up and crossfade animations when navigating between pages.
* **Responsive Design:** Carefully crafted layouts that look perfect on massive desktop monitors, tablets, and mobile devices.
* **Optimized Media:** Implements skeleton loading and CSS aspect-ratios to completely eliminate layout shifts when loading heavy case study images.

## 📂 Project Structure

* `/css` - Contains the core design system (`main.css`) and page-specific stylesheets.
* `/js` - Contains the theme toggle logic and scroll initialization.
* `/img` & `/explorations-img` - Optimized assets, mockups, and photography.
* `index.html` - The main landing page & hero section.
* `about.html` - A little bit about me and my journey!
* `*-case-study.html` - Deep dives into my UX projects (Citizen Connect, Recipely, etc).
